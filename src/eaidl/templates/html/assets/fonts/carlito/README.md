# Carlito

These unmodified font files come from the Google Fonts Carlito distribution:
https://github.com/google/fonts/tree/main/ofl/carlito

Carlito is a metric-compatible alternative to Calibri. The detailed EA SVG
renderer estimates text widths using Carlito metrics. Bundling the font keeps
HTML documentation independent of installed system fonts.

The font is licensed under the SIL Open Font License 1.1; see OFL.txt.
Keep the font assets with the generated documentation, including standalone
SVGs that reference them by relative URL.
